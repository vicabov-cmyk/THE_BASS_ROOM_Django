# THE BASS ROOM — навчальний сайт на Django + Bootstrap

Це **окремий Django-проєкт**. Він не змінює ваш `website` (SPORT ZONE / CAR ZONE).

## Що виконано

- Django-проєкт `config` + застосунок `bassroom`.
- Механізм шаблонів: `templates/base.html` і 5 сторінок у `templates/bassroom/`.
- Статика: `static/css/site.css`, `static/js/site.js`, `static/img/favicon.svg`.
- **Локально підключений Bootstrap 5.1.1** (`static/vendor/bootstrap/`) — інтернет для стилів не потрібний.
- Усі пункти навігації відкривають реальні Django-сторінки; меню працює на телефоні.
- Додані тести маршрутів.

## Як запустити на Mac у PyCharm

1. Розпакуйте `THE_BASS_ROOM_Django.zip`.
2. У PyCharm: **File → Open...** і виберіть папку `THE_BASS_ROOM_Django` (у ній є `manage.py`).
3. Відкрийте термінал PyCharm.
4. Якщо Django ще не встановлений у вибраному інтерпретаторі, введіть:
   `python3 -m pip install -r requirements.txt`
5. Запустіть:
   `python3 manage.py runserver 8001`
6. Відкрийте **http://127.0.0.1:8001/** у Safari.

> Використано порт 8001, щоб не заважати іншому проєкту, який може працювати на 8000.

## Адреси

- `/` — Головна
- `/events/` — Події
- `/artists/` — Артисти
- `/about/` — Про нас
- `/contacts/` — Контакти

## Як перевірити

У терміналі введіть `python3 manage.py test`. Очікування: тести перевіряють усі 5 сторінок і посилання.

## Важливе уточнення про завдання вчителя

В оригінальному завданні просять використати **конкретний готовий шаблон із KeepSimple20.rar**. У чаті був **лише скриншот архіву**, а не сам файл, тому цей проєкт — **окрема авторська стилізація на реальному Bootstrap**, а не буквальна переробка KeepSimple20. Якщо вчитель перевіряє обов'язкове використання саме файлів цього архіву, потрібно буде додати архів і перенести його розмітку/асети у Django.
